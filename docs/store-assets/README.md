# Store listing media

Canonical store-listing artwork for Drapeon.

- `android/play-phone/`: eight Google Play phone screenshots in listing order (`01` through `08`), 1080 x 1920.
- `ios/iphone-69/`: nine App Store iPhone screenshots in listing order, 1290 x 2796.
- `preview/drapeon_store_overview.png`: campaign/contact-sheet overview. This is not a store screenshot or a store-link Open Graph image.

Apple and Google generate previews for their own store URLs from the live listing. Drapeon-controlled URLs should use a dedicated 1200 x 630 Open Graph image instead of this overview collage.
